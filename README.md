# 📊 New Year Sales Analysis

## 📌 Project Overview

This project performs an Exploratory Data Analysis (EDA) on New Year sales data to uncover customer purchasing behavior, demographic trends, and business insights. The analysis focuses on identifying high-value customer segments, top-performing states, popular product categories, and other factors that influence sales.

The project is implemented using Python in Google Colab and leverages data analysis and visualization libraries to transform raw sales data into meaningful insights.

---

## 🎯 Objectives

- Clean and preprocess the sales dataset.
- Analyze customer demographics and purchasing patterns.
- Identify top-performing states and product categories.
- Examine customer spending based on gender, age, marital status, and occupation.
- Generate business insights through visualizations.

## 📊 Project Workflow

### 1. Data Collection
- Imported the New Year sales dataset.
- Loaded data using Pandas.

### 2. Data Cleaning
- Checked for missing values.
- Removed unnecessary columns.
- Dropped records with critical missing values.
- Converted data types for accurate analysis.

### 3. Exploratory Data Analysis (EDA)

The following analyses were performed:

- Gender Analysis
- Age Group Analysis
- State-wise Sales Analysis
- Marital Status Analysis
- Occupation Analysis
- Product Category Analysis

Multiple charts and visualizations were created using Matplotlib and Seaborn to identify trends and business insights.
